# GitHub Pages yayını

Depo: https://github.com/Fizyoappa/-yiad-m

Uygulama: https://fizyoappa.github.io/-yiad-m/

Uygulama dosyaları `docs/` içindedir. GitHub Pages ayarı: Settings → Pages → Deploy from a branch → `main` → `/docs`. `main` dalına gönderilen güncellemeler Pages tarafından yayımlanır.

Ziyaretçiler için GitHub veya ChatGPT hesabı gerekmez. Kullanıcı kayıtları tarayıcıda saklanır; bu depoya aktarılmaz.
